# CEFB Mobile App - Christ Embassy Farmers Branch

Official cross-platform mobile application for **Christ Embassy Farmers Branch (CEFB)** built with **Flutter & Dart**.

### Features
- **Live Stream & Video Sermons:** In-app YouTube and live service streaming with video playback controls (Chewie & Video Player).
- **Push Notifications:** Firebase Cloud Messaging (FCM) & local notifications for service announcements and live broadcasts.
- **Media Gallery & Events:** High-resolution image viewer with pinch-to-zoom (PhotoView) and cached network images.
- **Giving & Donations:** Embedded webview portal and payment gateway redirection for online giving.
- **Multi-Language Translation:** Integrated in-app translation features.
- **Cross-Platform:** Responsive UI optimized for Android and iOS devices.

### Tech Stack
- **Framework:** Flutter (Dart SDK >= 3.2.0)
- **State Management & Networking:** HTTP, SharedPreferences, DeviceInfoPlus
- **Cloud & Messaging:** Firebase Core, Firebase Cloud Messaging
- **Media:** Chewie, VideoPlayer, YouTube Player Flutter, PhotoView, CachedNetworkImage
- **UI & Design:** Material Design & Cupertino Icons, Google Fonts
